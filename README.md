# Security Investigation and Log Analysis Tool

A PowerShell-based security investigation tool developed as part of an Advanced Scripting module.

### **Overview**

This tool analyses multiple log files and identifies suspicious activity indicators before generating a security investigation report.

### **Features**

* Multi-log analysis
* Detection of suspicious events
* Automated report generation
* Structured output

### **Technologies**
* PowerShell

### **Learning Outcomes**

* Security monitoring
* Log analysis
* Automation
* Report generation
